# Runtime Assets

- `icon.svg`: Minty leaf icon used in the header, launch screen, favicon and fallback imagery.
- `icon.png`: 512px export of the icon.
- `favicon.png`: 64px browser tab icon.
- `apple-touch-icon.png`: 180px bookmark icon.
- `minty.jpg`: photo of Minty used as the page backdrop (1400px, resized from the original in `assets/source/`, which is kept out of git).

Keep only assets referenced by the launcher here. Store retired artwork and working exports outside the repository.
